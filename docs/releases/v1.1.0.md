# DSLM 1.1.0 — a second, richer model

DSLM runs small Llama 2 language models **entirely offline** on a Nintendo DS or DS Lite, launched from an R4 flashcart. Version 1.1.0 adds a second model to the package and lets you switch between them on the DS.

## Download and install

1. Download **`dslm-v1.1.0.zip`** below.
2. Unzip it at the **root** of your flashcart's microSD card (the kernel must already be installed). Upgrading from 1.0.0: unzip over the old files.
3. Launch `dslm.nds`. To switch models: SELECT, go down to `Model`, Left/Right, then START.

## What's New

- **tiny1m is included**: a model about four times larger than stories260K ([shibatch/tiny1m](https://huggingface.co/shibatch/tiny1m), MIT). Its stories are longer and more varied, with dialogue and more vocabulary.
- **Pick the model on the DS**: the Settings screen lists every model on the card, switches without a restart and remembers your choice. If a model does not fit in memory, the DS explains why and keeps the previous one.

## Changes and defaults

- Default model: **`stories260K_q80.bin`** (fastest, about 7 tokens/s). Choose **`tiny1m_q80.bin`** for richer stories at about 4.5 tokens/s.
- All three models (stories260K int8, tiny1m int8, stories260K fp32) share the tokenizer `tok512.bin`.
- `README-DSLM.txt`, `THIRD_PARTY.txt` and `MANIFEST.txt` list the new model.

## Bug Fixes

- The memory check before loading a model now counts memory released by the previous model, so switching models works without a restart.
- Release builds are byte-identical to local builds (sorted link order), so the published `dslm.nds` is exactly the one tested on hardware.

## Technical

| Model | Parameters | File | Tokens/s on a DS | Heap peak | Parity |
|---|---|---|---|---|---|
| stories260K int8 (default) | 260K | 0.5 MB | 6.87 | 1.37 MB | 197/197 vs host build |
| tiny1m int8 | ~0.9M (dim 128, 4 layers) | 1.0 MB | 4.44 | 2.42 MB | 60/60 vs host build |
| stories260K fp32 | 260K | 1.0 MB | 1.59 | 1.77 MB | 153/153 vs `run.c` |

- tiny1m is quantized with group size 32 (it divides dim 128 and hidden 352), so its int8 file is smaller per parameter than stories260K's (group size 4).
- The integer-only engine matches its own PC build bit for bit for both int8 models. Against the float reference `runq.c`, tiny1m follows for 7 to 128 generated tokens depending on the prompt (stories260K: 82 to 128); its text stays coherent.
- Measured on a Nintendo DS with an R4 clone (YSMenu kernel), DS hardware timers, `emulated=no`.
