# DSLM 1.2.0 — chat mode

DSLM runs small language models **entirely offline** on a Nintendo DS or DS Lite, launched from an R4 flashcart. Version 1.2.0 adds the first chat model: type a question, get an answer, all on the DS.

## Download and install

1. Download **`dslm-v1.2.0.zip`** below.
2. Unzip it at the **root** of your flashcart's microSD card (the kernel must already be installed). Upgrading from 1.0.0 or 1.1.0: unzip over the old files (your `dslm/dslm.ini` is replaced by the default one).
3. Launch `dslm.nds`. To chat: SELECT, go down to `Model`, Left/Right until `littlekedi_q80.bin chat`, then START. Back on the prompt screen, type a question (or press L/R for examples) and press START.

## What's New

- **Chat mode with LittleKedi** (experimental): [edededdy/LittleKedi-tiny-instruct](https://huggingface.co/edededdy/LittleKedi-tiny-instruct), a 2-million-parameter chat model (Apache-2.0). DSLM wraps your question in the model's chat format, shows it above the answer and stops when the answer ends.
- **A different kind of model**: LittleKedi follows the DeepSeek-V3 design (multi-head latent attention and a mixture of experts) with a GPT-2 tokenizer, so DSLM gained a second inference engine, integer-only like the first.
- **Honest expectations**: with 2M parameters the answers are fluent but often wrong or off-topic. It is a demonstration that a chat model runs on a 2004 handheld, not an assistant.

## Changes and defaults

- The default model is still **`stories260K_q80.bin`**. The story models keep working exactly as in 1.1.0.
- With a chat model, L/R cycle example questions instead of story starters, Steps only caps the answer's length, and the author's repeat penalty (1.15) is always on so answers do not loop. Each question starts a new chat; the model does not remember earlier ones.
- The package adds `dslm/models/littlekedi_q80.bin` (2.2 MB) and `dslm/models/littlekedi.tok` (its tokenizer, which must stay next to it). `THIRD_PARTY.txt` includes the Apache License 2.0.

## Bug Fixes

- Switching between a story model and a chat model from the story screen kept the previous prompt; it now switches to the new model's first example from any screen.

## Technical

| Model | Parameters | File | Tokens/s on a DS | Heap peak | Parity |
|---|---|---|---|---|---|
| LittleKedi int8 (chat) | 2.0M (dim 128, 4 layers, 8+1 experts) | 2.2 MB + 0.17 MB tokenizer | 2.81 | 3.42 MB | 263/263 vs host build |
| stories260K int8 (default) | 260K | 0.5 MB | 6.87 | 1.37 MB | 197/197 vs host build |
| tiny1m int8 | ~0.9M | 1.0 MB | 4.44 | 2.42 MB | 60/60 vs host build |

- Chain of evidence: llama.cpp (F16) = a numpy reference = DSLM's fp32 C engine, token for token; the int8 engine matches the fp32 one on 96% of positions (2.4% logit error), and where it differs llama.cpp's own Q8_0 gives the same answers (ADR 0010).
- New file formats MLQ1 (int8 matrices in groups of 32, the expert router kept in full precision) and BPE1 (byte-level BPE); the context is sized from the RAM left after loading, up to 1024 tokens.
- The integer kernels (RMSNorm, quantization, the ITCM matrix multiply, softmax, sampler) are now shared by both engines; the story models' outputs are bit-identical to 1.1.0.
- Measured on a Nintendo DS with an R4 clone (YSMenu kernel), DS hardware timers, `emulated=no`. The released `dslm.nds` differs from the measured build only by the version string and the prompt fix above.
